# Fonts

These match the SalesDay wordmark (brand guidelines, section 5).

- **Quicksand** (the "SALES" letters), variable weight 400 to 700, SIL Open Font License 1.1. Used for all interface text, at weights 400 to 600.
- **Codec Pro Regular** (the "day" letters), licensed CC BY 4.0, from onlinewebfonts.com. Used for headline numbers and the page title, always at Regular 400.
